# P2 设置页验收清单（模型管家）

用途：人工逐条勾选。对应 `docs/p2-acceptance.md` 的 C/F 段与 `docs/visual/review-002.md` 的问题编号。
环境：`pnpm dev:web` + 本地服务（`ws://<host>:8787`）；三档视口 1440 / 1280 / 768。
图例：`[ ]` 待验 / `[x]` 通过 / `[!]` 不通过（需写现象与复现步骤退回负责人）。

## 1. 入口与视图切换

- [ ] 顶栏模型选择器显示当前模型，长名称以省略号截断且悬停有 `title` 显示全名（P2-12）
- [ ] 点击模型选择器展开菜单，当前项有勾选标记；点击外部与按 Esc 都能关闭（P1-09）
- [ ] 菜单内模型项可键盘上下键导航，焦点可见，关闭后焦点回到触发按钮（P1-09/P2-13）
- [ ] 顶栏「设置」按钮进入设置页，标题「模型管家」与副标题可见
- [ ] 设置页「← 返回会话」回到原聊天视图，消息列表、当前会话、输入草稿保持不变（P1-08）
- [ ] 在 Usage tab 停留后切到聊天再返回，仍停留在 Usage tab（P1-08）
- [ ] 表单填了一半返回聊天再进来，有草稿保留或明确的「丢弃未保存修改」提示（P1-08）

## 2. Providers 表单校验与错误提示

- [ ] 点击「+ 新增提供商」展开表单，名称/Base URL/模型 ID/API Key/启用开关字段齐全
- [ ] 名称留空提交，字段旁出现明确红字错误，输入框 `aria-invalid=true`，不关闭表单（P0-04）
- [ ] 名称只输入空格提交，同样被拦截（不能靠 `required` 放行）（P0-04）
- [ ] Base URL 留空或被截断成 `abc` 时提示「请输入合法的 http(s) URL」，不是浏览器气泡（P0-04）
- [ ] 模型 ID 完全留空提交被拦截，提示「至少填写一个模型 ID」（P0-03）
- [ ] 模型 ID 用英文逗号、中文逗号、换行三种分隔都能正确拆分并去空
- [ ] 多个字段同时出错时，所有错误一次性列出，而不是一次只报一个
- [ ] 错误文案在 1440/1280/768 三档都不换行撑破表单卡片
- [ ] 编辑既有 provider 时 API Key 留空，保存后原 key 仍生效（提示文案为「留空表示不修改」）
- [ ] Esc 可关闭表单且不丢失已填内容（P1-09）

## 3. 保存中 / 保存失败 / 删除中状态

- [ ] 点击保存后立即出现「保存中…」且按钮禁用，直到收到结果（P0-02）
- [ ] 保存成功后表单关闭，列表出现新条目，并有短暂成功提示（P0-02）
- [ ] 模拟服务端返回 error：表单保持打开、内容不丢、页内显示错误文案（P0-01/P0-02）
- [ ] 断网状态下进入设置页，显示「连接已断开，保存/删除暂不可用」而非仅禁用按钮（P0-01）
- [ ] 删除点击确认后出现「删除中…」，该行按钮禁用，连点不重复发送（P0-02）
- [ ] 删除失败时条目仍在列表且显示错误原因（P0-01/P0-02）
- [ ] 首次进入设置页、数据未回包时显示加载态，不闪「还没有提供商」（P1-11）

## 4. 列表与危险操作

- [ ] 新增的 provider 卡片显示名称、启用徽标、Base URL、模型数、API Key 提示
- [ ] 编辑后卡片字段即时更新，不需要刷新整页
- [ ] 点击删除弹出确认，文案包含 provider 名称、不可撤销说明、模型与用量影响（P1-05）
- [ ] 确认弹层默认聚焦「取消」，按 Esc 可取消且焦点回到原删除按钮（P1-05）
- [ ] 取消删除后条目保持不变；确认删除后条目消失，空态重新出现
- [ ] 删除按钮有可读名称 `删除提供商 <名称>`，读屏可区分不同卡片（P1-05）

## 5. 空态

- [ ] 没有任何 provider 时显示虚线空态「还没有提供商，先加一个」及引导文案（P1-11）
- [ ] 空态中的引导文案与「+ 新增提供商」按钮在 768 下都可见，无需横向滚动
- [ ] 没有用量数据时「按提供商」表格显示「暂无用量数据」（P1-11）
- [ ] 没有调用记录时「最近记录」表格显示「暂无调用记录」（P1-11）
- [ ] 汇总为 null（未加载）时统计卡显示「—」而不是醒目的 `0`（P1-11）

## 6. 长文本截断

- [ ] 超长 provider 名称截断为省略号，悬停 `title` 显示全名（P1-06）
- [ ] 超长 baseUrl（>120 字符）不撑高卡片，同行卡片高度一致（P1-06）
- [ ] 超长 apiKeyHint 不换行撑破卡片，悬停可读完整提示（P1-06）
- [ ] 用量表格的长模型名有 `max-width` + 省略号 + `title`，不必整表横滚（P1-07）
- [ ] 顶栏模型选择器在长模型名下仍保持按钮宽度上限，不挤压「设置」按钮

## 7. 768 宽响应式

- [ ] 768 视口下设置页无整页横向滚动（`document.scrollWidth <= clientWidth`）
- [ ] `.form-grid` 变为单列，两个宽字段正常占满，标签与输入框不重叠
- [ ] `.panel-head` 纵向排列，标题与「+ 新增提供商」按钮不重叠、间距舒适（P2-15）
- [ ] provider 卡片单列铺满，卡片内部 key/value 对齐，徽标不被挤压
- [ ] 统计卡在 768 下仍可读且不过度堆叠（若保留三列需确认数字不溢出）（P2-15）
- [ ] 两张表格在 768 下通过 `.table-wrap` 局部横滚，不带动整页滚动
- [ ] 保存 768 视口截图 `settings-768.png` 供设计复核

## 8. 键盘与无障碍

- [ ] 仅用 Tab 可走完「返回 → tab → 新增 → 表单字段 → 保存/取消 → 卡片编辑/删除」且顺序符合视觉
- [ ] 所有按钮与输入框在 `:focus-visible` 下有 2px 以上可见焦点环（P2-13）
- [ ] 「提供商 / 用量」tab 有 `aria-selected`，左右方向键可切换（P1-10）
- [ ] tabpanel 有 `role="tabpanel"` 并通过 `aria-labelledby` 关联到当前 tab（P1-10）
- [ ] 错误提示使用 `role="alert"`，读屏会播报（P0-04/P0-01）
- [ ] 失败记录的错误原因读屏可读（非仅 `title`）（P2-14）

## 9. 用量 Tab

- [ ] 汇总卡显示总请求、总输入 token、总输出 token，千分位格式正确
- [ ] 「按提供商」表格按 `summary.byProvider` 正确分组，数值与总量一致
- [ ] 最近记录最多 50 条，按时间倒序
- [ ] 成功/失败有不同颜色标签，失败行有可读原因（P2-14）
- [ ] 记录时间包含年月日，跨年数据不混淆（P2-14）

## 10. 回归

- [ ] 设置页所有操作后返回聊天，发送一条消息仍正常收到 assistant 回复
- [ ] `pnpm --filter @witcode/web typecheck` 与 `build` 通过
- [ ] `pnpm exec playwright test docs/visual/playwright-settings.spec.ts` 全部通过（需先安装 `@playwright/test`）
