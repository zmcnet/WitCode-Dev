# ZCode 4.0.0 Web 端布局与视觉结构

> 来源：只读探索（研究员 B）
> 用途：WitCode Web 工作台的布局蓝本
> 结论：ZCode Web 是「2 栏默认 / 3 栏可选」；布局可抄，品牌不可抄。

---

## 1. 整体结构

宽屏默认两栏：左栏 264px + 中间对话区。右栏和底部终端默认关闭，需要时展开。

```
DesktopWindowFrame
└─ WorkspaceShellLayout
   ├─ Sidebar (264px, max 50% 壳宽, 可拖拽)
   │  ├─ 48px 拖拽/留白
   │  ├─ 主导航（新建任务 / 自动化 / 插件商店 / 扩展）
   │  ├─ 列表头（标题 / 搜索 / 视图菜单）
   │  ├─ 滚动列表（置顶 / 项目 / 任务）
   │  └─ Footer（账号 / 套餐 / 设置）
   ├─ 拖拽条（4px 命中区 + 2px 指示线）
   └─ 内容区（min 320px）
      ├─ 对话列（默认 52%，min 360px）
      │  ├─ 顶栏 48px（项目 / 标题 / 右侧动作）
      │  ├─ 消息区（独立滚动）
      │  └─ 输入区（sticky 底部）
      └─ 右栏（默认 0，展开 45%，min 240px）
         └─ 48px tab 栏 + 内容
```

关键尺寸：

| 区域 | 数值 |
|---|---|
| 左栏 | 默认/最小 264px，最大 50% 壳宽，可拖拽，宽度持久化 |
| 对话列 | 最小 360px |
| 内容列 | 有消息 max-w-6xl（1152px）；草稿 max-w-2xl（672px） |
| 右栏 | 默认 0，展开 45%，最小 240px |
| 底部终端 | 默认 0，展开 30%，最小 140px |
| 顶栏 / 右栏 tab 栏 | 48px |
| 断点 | md 768 / lg 1024 / xl 1280 |
| 自动收起 | 壳宽 <360 收左栏，<480 关右栏，resize 停止 300ms 后执行 |

---

## 2. 左栏

- 顶部没有品牌 logo，只有 48px 留白/拖拽区。
- 主导航四项：新建任务（h-8）、自动化、插件商店、扩展槽位。
- 列表头固定不滚动：标题 + 搜索 + 视图菜单。
- 视图四种：按项目 / 按任务组 / 最近更新 / 未读。
- 列表顺序：置顶任务（最多 20）→ 置顶项目 → 可折叠「项目」→「任务」。
- 项目行 h-8，显示图标、名称、设备、未读点；展开后内嵌任务。
- 任务行显示标题、工作区、时间、运行状态、未读点、+/- 变更数。
- 底部：头像 + 用户名 + 套餐徽标 + 设置齿轮。

---

## 3. 顶栏

- 48px，`border-b`，仅在已有任务时显示；草稿态不显示。
- 左侧：项目/工作区按钮（弹层显示路径、最近活动、分支）→ 任务标题 → 更多。
- 右侧：编辑器选择、分享、帮助、终端开关、右栏开关。
- **模型不在顶栏**：模型在输入区右下；分支在输入框上方。
- 不是 `sticky`，而是对话 frame 内的固定 flex 子项。

---

## 4. 对话区

- 用户消息：右对齐气泡，`rounded-xl` + `border` + `bg-surface`，宽屏 `max-w-xl`（576px），无头像。
- 助手消息：**整列全宽，无气泡、无头像**，直接 Markdown 正文。
- 工具调用：**内联摘要行**（图标 + 类别 + 主文本 + 次文本 + 状态 + diff 数），可展开；不是大卡片。
- 文件变更：单独卡片（标题 + `+added/-removed` + 文件行 + Review 按钮）。
- 代码块：`rounded-xl` 外框，头部语言/换行/复制。
- 消息列 `max-w-6xl` 居中，轮次间距约 20px，有回到底部浮钮。
- 运行状态以输入框上方的胶囊行呈现。

---

## 5. 输入区

- 消息区底部 sticky dock，宽度与消息列一致。
- 输入壳 `rounded-2xl`，`border`，内边距 12px。
- 自上而下：context header（草稿态：项目 + 分支 + worktree）→ 编辑器 → 工具条。
- 左下：模式切换、Hook/MCP 入口、CUA 入口、`+` 菜单（附件 / `/` 命令 / `@` 提及）。
- 右下：扩展槽 → 上下文用量圆环 → 模型选择 → 思考深度 → 语音 → 发送/停止。
- Enter 发送，Esc 停止。
- 错误横幅在输入壳之外、状态行之上。

---

## 6. 右栏

- 默认关闭；顶栏按钮或打开文件/审查时自动打开。
- 展开 45%，min 240px；对话列 min 360 是事实上限。
- tab 栏 48px：总览下拉 → 当前标签（60–156px 弹性）→ 溢出 `+` → 关闭/全屏。
- 可承载：文件树、Git diff、终端、内嵌浏览器、计划详情、子代理、工作流、插件 UI、模型轨迹等。
- 手机远控下变成全屏右侧抽屉。

---

## 7. 设置页

- 不是弹窗，是**整页覆盖层**：底层工作区保持挂载但 `inert`。
- 布局：`grid-cols-[68px_1fr]`，`lg` 起 268px。
- 左栏：48px 留白 → 返回工作区 → 搜索 → 分组导航 → 账号 footer。
- 分组：基础 / Agent 能力 / 数据与统计；共 20+ 分区（常规、外观、模型供应商、快捷键、Agent 行为、记忆、子代理、插件、MCP、技能、用量…）。
- 内容区：独立面板，顶部 48px 面包屑，内容 `max-w-4xl`，可滚动。
- 窄屏：左栏收成 68px 图标 rail；`compact-web` 变顶部横向滚动。

---

## 8. 空态

- 新建任务：问候语 + 大号 Z 水印 + 建议提示词 + 居中输入框，整组 `max-w-2xl`。
- 顶部留白 `29dvh`，标题字号 20–30px 自适应。
- 建议提示词支持 chips / list 两种密度。

---

## 9. 视觉 token（只抄方法，不抄品牌）

| 语义 | Zai Light | Zai Dark |
|---|---|---|
| 页面背景 | `#f8f8f8` | `#161616` |
| Header/Panel | `#ffffff` | `#202020` |
| Sidebar | `#f0f0f0` | `#161616` |
| Card/Popover | `#ffffff` | `#2b2b2b` |
| Border | `rgba(13,13,13,.1)` | `rgba(255,255,255,.1)` |
| 品牌色 | `#000000` | `#ffffff` |

- 基础字号 14px；阶梯 18/16/14/13/12/10/9。
- 间距基数 4px；常用 4/8/12/16/20–24。
- 圆角：首层 `xl`，嵌套 `lg → md → sm`；输入壳/对话框可 `2xl`；菜单 `lg`。
- 控件高度 24/28/32/36；图标默认 16。
- 背景层次优先于阴影；弹层用 `shadow-md`，普通布局不用大阴影。

**不要抄**：Z 标志、黑白品牌色、Zai 主题命名、ZCode 产品名、欢迎语、商业化徽标、桌面窗控。

## 10. WitCode 可照搬清单

| 优先级 | 布局项 | 做法 |
|---|---|---|
| P0 | 三区壳层 | 左 264 + 中对话 flex + 右可选 45%；对话列 min 360 |
| P0 | 对话内容列 | 常规 max-w-6xl，草稿 max-w-2xl |
| P0 | 左栏四段式 | 主操作 → 列表头 → 滚动列表 → footer |
| P0 | 48px 顶栏 | 项目 + 标题 + 右侧动作；模型放输入区 |
| P0 | 底部 sticky 输入 | rounded-2xl 壳 + 上方 context + 下方工具条 |
| P0 | 用户右气泡 / 助手全宽 | 用户 max-w-xl；助手无气泡 Markdown |
| P0 | 工具调用内联摘要 | 摘要行 + 展开；文件变更单独卡片 |
| P0 | 整页设置 | 全屏覆盖 + 68/268 导航 + max-w-4xl |
| P0 | 设计 token | 14px 基准、4px 间距、xl/lg/md/sm 圆角 |
| P1 | 右栏 tab 化 | 48px tab 栏、可拖拽、可关闭、`+` 启动器 |
| P1 | 底部终端 | 默认关、30% 展开、min 140 |
| P1 | 任务视图切换 | 按项目/按组/最近/未读 |
| P1 | 草稿空态 | 问候 + 水印（换 WitCode 图形）+ 建议 chips |
| P1 | 响应式 | <1024 设置图标 rail；<640 横向设置导航；手机两页式 |
| P1 | 自动收起 | <360 收左栏、<480 关右栏，resize 停止后执行 |

## 11. 与 WitCode 现状的差距

| 项 | 现状 | 目标 |
|---|---|---|
| 布局 | 左栏 + 消息区，无右栏/终端 | 三区壳层，右栏可选 |
| 左栏 | 简单会话列表 | 四段式 + 视图切换 + footer |
| 顶栏 | 品牌 + 模型 + 设置 | 项目 + 标题 + 动作；模型移到输入区 |
| 助手消息 | 气泡 | 全宽 Markdown |
| 工具调用 | 卡片 | 内联摘要 + 展开 |
| 输入区 | 单行框 + 按钮 | rounded-2xl 壳 + 工具条 |
| 设置 | 整页切换（已接近） | 整页覆盖 + 左侧二级导航 |
| 移动端 | 抽屉 | 两页式 + 右栏抽屉 |
