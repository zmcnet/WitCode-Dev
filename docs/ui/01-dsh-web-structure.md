# DSH Web 端功能结构与信息架构

> 来源：只读探索（研究员 A）
> 用途：WitCode Web 工作台的功能蓝本
> 结论：DSH 是「三栏壳 + 无全局顶栏 + 右栏 dock + 设置模态」；功能结构可抄，皮肤不可抄。

---

## 1. 整体布局

| 区域 | 规则 |
|---|---|
| 左栏 | 默认 280px；拖拽 264–420；<1024 折叠为 56px 图标轨；<768 覆盖式抽屉 |
| 中栏 | `1fr`；右栏打开时保底 400px |
| 右栏 | 首次 45%；最小 300；最大 70%；关闭时轨道 0 |
| 底部行 | 占满三栏的独立 grid 行 |
| 断点 | 1024 / 768 |

列宽求解顺序：先压右栏 → 丢掉右栏轨道 → 最后才让中栏低于最小值。

```
AppFrame (grid: sidebar | center | rightbar)
├─ SidebarRoot
│  ├─ logoRow（品牌 + 折叠）
│  ├─ newSessionRow
│  ├─ scrollRegion
│  │  ├─ nav.panelList（插件 / 任务 / More）
│  │  └─ WorkspaceBrowser（工作区/会话树）
│  └─ footArea（设置 / 账号 / 连接状态）
├─ MainPanel（keyed slot）
│  ├─ conversation → 会话 header + 消息流 + composer
│  ├─ plugins
│  └─ schedules
├─ Rightbar（pane tab strip + body）
├─ bottomRow
├─ overlayLayer
└─ leadingSeat（左栏隐藏时的展开/新建按钮）
```

---

## 2. 导航与页面

- **没有 URL 路由**，主面板由 `activePanelId` 驱动：`null` = 会话，其他 = plugins / schedules。
- 切换主面板不改变当前 Session。
- 设置是模态，不占主面板。
- 会话内视图 tab：Chat / Trajectory（回合轨迹）。

---

## 3. 左栏与会话列表

### 结构

- 顶：品牌 + 折叠按钮；展开态品牌可点击新建会话。
- 新建会话行（显示快捷键）。
- 面板导航：插件、定时任务、More（可置顶）。
- 工作区/会话树。
- 底部：footer actions + 设置/账号/连接状态。

### 会话列表

- 分组三选一：按工作区 / 按工作区树（嵌套目录）/ 单列表。
- 未归属工作区的会话进「未分组」。
- 排序：手动 / 最近更新。
- 归档过滤：隐藏 / 显示 / 仅归档。
- 每个工作区默认露 5 条；运行中、待审批、未读、当前会话自动抬高。
- **不按日期分桶**。

### 会话行

- 32px 行高。
- 左：状态槽（状态点 / 扩展位）。
- 中：标题（可跑马灯；空会话「新会话」，无标题「未命名」）。
- 右：相对时间，或被「等待审批 / 计划评审 / 提问」标签替换。
- 置顶标记；hover 出现「…」菜单。
- 状态优先级：审批/计划评审/提问 > 运行中的子代理 > 完成未读/失败。

### 动作

- 新建（顶部 / 品牌 / 工作区行「+」）。
- 重命名（双击 / 右键）。
- 置顶、标已读/未读、分叉、复制 Session ID。
- 归档/恢复（**不做物理删除**；运行中归档需二次确认）。
- 搜索：标题本地匹配 + 内容服务端搜索，250ms 防抖，结果带工作区与片段。

## 4. 对话区

### 消息类型

| 类型 | 呈现 |
|---|---|
| 用户 | 右对齐气泡，最大约内容列 70–82% |
| 附件 | 图片缩略图组 / 文件卡 |
| 助手 | **无气泡，全宽 Markdown 流式** |
| 思考 | 独立折叠行，运行中显示流式摘要 |
| 工具调用 | 紧凑 DisclosureRow，与文本按 step 交织 |
| 回合过程 | 「已完成，用时 X」+ 工具/消息/子代理计数，可折叠 |
| 错误 | 红色状态点 + 标题 + 失败消息 + 错误码 |
| 达到最大 token | 警告行 + 解释 |
| 压缩/继承历史/系统提示/上下文注入 | 各自专用行 |
| 审批/提问 | **接管 composer**，不插入消息流 |

### 回合轨

- 右侧固定轨，每回合一个刻度，可点击跳转、悬停预览。
- 容器 <900px 时隐藏。
- 回合内按 step 聚合：过程可折叠，答案保留在外。

### 工具行

- 图标 + 标题 + 摘要 + 状态；整行可展开。
- 摘要支持文件链接、URL、Diff 增删、退出码徽标。
- 展开后按类型渲染：终端块、Diff、Read/Search/Web、图片、问答卡、原始 JSON。
- 子调用递归嵌套。
- 有 `data-chat-call-id` 锚点，可从 Trajectory 跳转。

### token / 耗时

- 回合过程行显示耗时。
- 回合尾部有 Token 用量按钮，弹层列输入/缓存读/缓存写/输出/推理 + 模型路由。
- Composer 下方常驻「活动/用量」胶囊。
- 输入框下方有上下文占用环。

## 5. 输入区

```
InputBar
├─ notice / Toast
├─ 输入卡片
│  ├─ overlay 锚点（命令/引用菜单）
│  ├─ accessory（工作区行）
│  ├─ attachments（图片/文件条）
│  ├─ DraftEditor（contenteditable，最大 336px ≈ 14 行）
│  └─ 工具行
│     ├─ 左：+ 菜单、文件、权限、计划
│     └─ 右：扩展、模型、活动、停止/发送
└─ dock：Queue / Todo + ContextMeter
```

- `/` 命令 chip、`@` 文件/会话引用、引用块、IME 保护。
- Enter 发送，Shift+Enter 换行，Cmd/Ctrl+Enter 插话。
- 运行中提交普通文本 → 插话/排队。
- 队列 Dock 在输入框上方：可编辑、删除、插话。
- Todo 面板在输入框上方。
- 审批/提问接管 composer。

---

## 6. 右栏

- 每个 Session 一个右栏 dock，状态保存在会话作用域，刷新恢复。
- 顶部 38px tab strip + 38px pane header，与中栏 76px header 对齐。
- 支持多 tab、分栏、浮窗、全屏、拖拽宽度。
- 内置 tab：guide、files、text、browser、terminal、plan、changes-review、scheduleTask、subagentchat、compaction-summary。
- 打开：折叠时 header 右下角「展开右栏」按钮；关闭：tab strip 末端折叠按钮。
- <768 自动全屏，不占中栏轨道。

### Session Panel

- 独立于右栏，是对话内浮动辅助卡，贴内容列右侧。
- 最小 300px，空间不足变 280px 覆盖卡。
- 内容：环境/项目、变更请求、子代理、后台任务。

---

## 7. 顶栏

**DSH 没有全局顶栏。**

| 元素 | 位置 |
|---|---|
| 品牌 | 左栏顶部 |
| 当前会话 | 中栏会话 header（标题/面包屑） |
| 模型 | 输入框右下角 |
| 连接状态 | 左栏底部 |
| 设置入口 | 左栏底部账号菜单 |

---

## 8. 设置

- 模态：遮罩 + `role="dialog"`，桌面 824×800，两列 212px 导航 + 内容。
- 导航竖向分区：账号 / 通用 / 模型 / 插件 / Agent 预设 / 远程连接。
- 「通用」是行容器：权限、语言、主题、字号、对话视图、链接打开、开发者工具、快捷键、Enter 行为、日志上传、更新通道、版本。
- 主题/语言/快捷键**没有独立 tab**，都是「通用」里的行。
- <767 全屏 + 顶部横向分区条。

---

## 9. 空态

- 无当前会话：hero 相位，居中标题 + 徽章 + 工作区 chip + 输入框。
- 未选工作区：输入框 inert，点击打开工作区选择。
- 没有示例提示词画廊。
- 首次使用两层模态：预览版说明 + 添加 API Key 引导。

---

## 10. 移动端

- <1024 左栏折叠为 56px rail；<768 覆盖式抽屉 + 遮罩。
- 抽屉打开时中栏/右栏 `inert`，焦点锁在抽屉。
- 完全隐藏左栏时，展开/新建按钮移到左上 leading 座位。
- 右栏 <768 自动全屏。
- 设置 <767 全屏 + 顶部横向条。
- 回合轨 <900px 隐藏。
- 没有底部 Tab 导航。

---

## 11. 可照搬清单

### P0

1. 三栏壳：左 280（264–420/56 rail）、中保底 400、右 300–70%（首次 45%）。
2. 主面板状态机：conversation / plugins / schedules，切换不丢会话，不引入 URL 路由。
3. 左栏四段式：品牌+新建 / 面板入口 / 工作区会话树 / 底部账号+设置+连接。
4. 会话按工作区分组：工作区树、平铺、未分组；排序手动/最近；归档三态。
5. 会话行动作：新建、重命名、置顶、归档/恢复、分叉、复制 ID、已读/未读；不做物理删除。
6. 会话搜索：本地标题 + 内容搜索，防抖，带片段。
7. 对话 header：面包屑标题 + Chat/Trajectory tab + 右侧工具。
8. 消息分层：用户气泡 / 助手全宽 / 思考折叠 / 工具行 / 回合过程 / 错误行。
9. 输入卡片：contenteditable 自动增高、附件条、`+` 命令、权限/计划、模型 chip、发送/停止。
10. Composer dock：队列 + 待办 + 审批接管。

### P1

11. 右栏 dock：guide + files/text/terminal/browser/changes-review/plan/task/subagent。
12. 右栏入口：header 展开按钮 + tab strip 折叠 + 快捷键；窄屏全屏。
13. Session Panel：环境/项目、变更、子代理、后台任务。
14. 设置模态：左导航 + 分区内容；「通用」用行插件。
15. 首次使用引导：预览说明 + API Key 引导。

---

## 12. 功能结构 vs 视觉皮肤

| 可借鉴 | 不要照抄 |
|---|---|
| 三栏壳、列宽求解、拖拽与断点 | macOS 毛玻璃 sidebar tint |
| slot 化 sidebar/main/rightbar/overlay/leading | 鲸鱼 hero 动画 |
| 右栏 dock 的 tab/分栏/浮窗/全屏 | 官方品牌 mark、像素鲸鱼 |
| 会话行状态语义 | 品牌字体、具体圆角/阴影/蓝色 token |
| 设置模态的「导航 + 分区」 | 824×800、212px 等具体数值（可参考，非规范） |
| Composer 常驻 + 队列/待办/审批接管 | 胶囊样式、shimmer、鲸鱼尾动画 |
