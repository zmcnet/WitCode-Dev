# WitCode Web 界面融合方案

> 输入：`01-dsh-web-structure.md`（功能结构）+ `02-zcode-web-layout.md`（页面布局）
> 用户要求：**功能照 DSH 抄，页面照 ZCode 抄**
> 结论：两家在“对话呈现”上高度一致，差异只在壳层；按用户偏好裁决后，形成一套明确目标。

---

## 1. 融合原则

| 维度 | 取自 | 说明 |
|---|---|---|
| 三区壳、列宽、拖拽 | ZCode | 左 264 + 中对话 + 右可选 |
| 48px 顶栏 | ZCode | 用户要“页面像 ZCode” |
| 整页设置 | ZCode | 全屏覆盖 + 左侧二级导航 |
| 视觉 token 结构 | ZCode | 14px 基准、4px 间距、xl/lg/md 圆角 |
| 左栏信息架构 | DSH | 品牌+新建 / 面板入口 / 工作区树 / 底部账号 |
| 会话状态语义 | DSH | 审批/运行/未读/失败优先级 |
| 右栏 dock | DSH | tab 化：文件/终端/Diff/计划/浏览器 |
| 回合轨 + Trajectory | DSH | 长任务可回看 |
| Composer dock | DSH | 队列 / 待办 / 审批接管 |
| 消息分层 | 两家一致 | 用户气泡、助手全宽、工具行 |
| 品牌色/图标 | WitCode 自己 | 不抄 Z 标志、不抄 DSH 鲸鱼 |

## 3. 尺寸与断点

| 区域 | 值 |
|---|---|
| 顶栏 | 48px，`border-b` |
| 左栏 | 264px，可拖拽 240–420，折叠为 0（Web） |
| 对话列 | 最小 360px |
| 内容列 | 有消息 `max-w-6xl`（1152）；草稿 `max-w-2xl`（672） |
| 右栏 | 默认 0；展开 45%；最小 240；最大 70% |
| 底部终端 | 默认 0；展开 30%；最小 140 |
| 设置导航 | 68px 图标轨 / 268px 展开 |
| 断点 | 1024（左栏 rail / 设置图标轨）、768（左栏抽屉、右栏全屏）、640（设置顶部横向） |

## 4. 各区域设计

### 4.1 顶栏（ZCode 壳 + DSH 语义）

- 左：项目/工作区按钮（弹层显示路径、分支、最近活动）→ 会话标题（可编辑）。
- 右：右栏开关、终端开关、分享（后续）、设置。
- **不放模型**：模型在输入区右下（两家一致）。
- 只在有会话时显示；草稿态显示品牌 + 工作区。

### 4.2 左栏（ZCode 四段式 + DSH 工作区树）

```
品牌 + 新建会话
────────────
导航：会话 / 插件 / 定时任务（可折叠）
────────────
搜索框 + 视图切换（按项目 / 最近 / 未读）
工作区树：
  项目 A
    ├ 会话 1  [运行中] [未读]
    └ 会话 2
  项目 B
    └ …
────────────
账号 / 设置 / 连接状态
```

- 会话行 32px：状态点 + 标题 + 相对时间/状态标签 + 置顶。
- 状态优先级：待审批 > 运行中子代理 > 未读/失败。
- hover 出现「…」：重命名、置顶、归档、分叉、复制 ID。
- 不做物理删除，只归档。
- 搜索：本地标题 + 内容搜索，250ms 防抖。

### 4.3 对话区

- 用户：右对齐气泡，`max-w-xl`，`rounded-xl`。
- 助手：全宽 Markdown，无气泡无头像。
- 思考：折叠行，运行中显示摘要。
- 工具：内联摘要行（图标 + 名称 + 摘要 + 状态 + diff 数），可展开；文件变更单独卡片。
- 回合过程：「已完成，用时 X · N 个工具」，可折叠。
- 错误：红色状态 + 消息 + 可重试。
- 回合轨：右侧刻度，>900px 显示。
- Trajectory tab：后续接入，显示每步模型请求与工具调用。

### 4.4 输入区（ZCode 壳 + DSH dock）

```
[附件条]
┌──────────────────────────────────────────┐
│ 输入框（自动增高，最多 14 行）            │
│ [+ 命令] [权限] [计划]      [模型] [发送] │
└──────────────────────────────────────────┘
[队列 / 待办 / 审批接管]
```

- `rounded-2xl` 壳，`border`，内边距 12px。
- Enter 发送，Shift+Enter 换行。
- 运行中发送 → 插话/排队（先做排队）。
- 审批/提问接管输入区，不插入消息流。
- 模型 chip 显示 `provider/model + effort`。

### 4.5 右栏（DSH dock）

- 默认关闭；顶栏按钮或打开文件/审查时自动开。
- tab 栏 48px，可拖拽、可关闭、`+` 启动器。
- P0 tab：文件、终端、Diff、计划。
- P1 tab：浏览器、子代理、任务详情。
- 窄屏 <768 自动全屏。

### 4.6 设置（ZCode 整页 + DSH 分区）

- 整页覆盖，底层工作区 `inert`。
- 左侧导航 268px（<1024 收 68px 图标轨）：
  - 通用（外观、语言、快捷键）
  - 模型（Providers / 用量）
  - **Brains**（新增：选择/查看每个脑子）
  - 插件
  - 会话与数据
  - 关于
- 内容区 `max-w-4xl`，独立滚动。

### 4.7 空态

- 品牌 + 一句定位 + 工作区选择 + 居中输入框。
- 建议提示词 chips（可选，P1）。
- 不抄 ZCode 的 Z 水印、不抄 DSH 的鲸鱼。

## 7. 验收标准

### P0

1. 1440 宽：左 264 + 对话 + 顶栏 48，无横向溢出。
2. 助手消息全宽、无气泡；用户消息右气泡。
3. 工具调用显示为一行摘要，可展开看到参数/结果。
4. 输入区为 rounded 壳，模型 chip 在右下，发送/停止状态正确。
5. 设置整页覆盖，左侧导航可切换，Brains 页能看到当前脑子。
6. 1280 / 768 / 390 三档无溢出；390 下左栏抽屉、消息区全宽。
7. `pnpm -r typecheck` / `test` / `build` 全过。

### P1

1. 右栏可开可关，文件/终端/Diff/计划四个 tab 可用。
2. 会话可重命名、置顶、归档、搜索。
3. 队列在输入框上方可见，可删除。
4. 回合轨可点击跳转。
5. 截图验收：桌面 1440 + 移动 390 各一套。

## 8. 不做

- 不抄 ZCode 的 Z 标志、黑白品牌色、Zai 主题命名。
- 不抄 DSH 的鲸鱼、毛玻璃、品牌字体。
- 不做 URL 路由（主面板用状态机）。
- 不做物理删除会话（只归档）。
- P0 不做内嵌浏览器、白板、终端多开。
